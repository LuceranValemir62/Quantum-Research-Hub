# Contributing to Quantum Research Hub

## Code of Conduct
This project adheres to professional academic and engineering standards. 
Be respectful, constructive, and evidence-based in all discussions.

## How to Contribute

### 1. Reporting Issues
- Use the issue template
- Provide quantum framework versions (Qiskit, Cirq, etc.)
- Include minimal reproducible examples

### 2. Submitting Code
- Fork the repository
- Create a feature branch: `git checkout -b feature/your-feature-name`
- Follow PEP 8 style guidelines
- Write unit tests for all quantum circuits and algorithms
- Update documentation

### 3. Documentation Standards
- All algorithms must include:
  - Mathematical formulation (LaTeX)
  - Complexity analysis
  - References to original papers
  - Usage examples
